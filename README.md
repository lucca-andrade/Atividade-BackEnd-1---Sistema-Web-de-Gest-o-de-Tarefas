# Sistema Web de Gestão de Tarefas

Projeto inicial para organização e gerenciamento de tarefas.

## Objetivo

O projeto tem como objetivo desenvolver um sistema web para auxiliar na
organização, criação e gerenciamento de tarefas.

## Pré-requisito

-   Python 3 instalado.
-   Git instalado (opcional, para versionamento do projeto).

## Execução

### 1. Criar o ambiente virtual

python -m venv .venv

### 2. Ativar o ambiente virtual no Windows

Como a prática está sendo realizada no Windows PowerShell:

.\.venv\Scripts\Activate

Quando o ambiente estiver ativo, o terminal deverá apresentar `(.venv)` no início da linha.

Para desativar o ambiente virtual:
deactivate

### 3. Executar o script

Com o ambiente virtual ativado:
python main.py
